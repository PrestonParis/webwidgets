# Prompts (archive)

This directory and `docs/agents/completions/` are the historical record of
Stage-1 work coordinated through the local prompt-queue workflow described
in `docs/agents/workflow/GEMINI.md`. That workflow is superseded — new work
is tracked as GitHub issues, not new files here. See
[/AGENTS.md](../../../AGENTS.md) §11.

The 32 numbered prompts in this directory are all marked `Status: Complete`
in place (per `docs/agents/workflow/GEMINI.md`'s process, they were meant to
move to `completions/` on completion; in practice they didn't — this is
noted rather than fixed retroactively, since it's just history at this
point).
